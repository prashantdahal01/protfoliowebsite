A small set of well-named tokens can do more for a growing interface than a large component library with unclear boundaries.

I look for repeated decisions first: spacing rhythm, border treatment, text measure, and interaction feedback. Once those decisions are named, components become easier to compose and easier to change.

The system is not the visual layer. It is the agreement that lets the visual layer stay coherent.
